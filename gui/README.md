# Zero 2 自定义键盘 GUI（改键 + 一键刷写）

Windows 小工具，界面参考 **Xbox Accessories 的按键映射**：左边是官方 Zero 2 产品渲染图，
**点手柄上的某个键**（亮蓝圈）→ 右边选择它要输出的键盘键；还能把当前这套键位
**命名保存成「我的设定」**，下次一键载入。

刷写时自动生成固件、起本地代理、打开官方 8BitDo Firmware Updater 并自动完成
「高级模式 → Zero 2 → 更新」，把自定义固件写进手柄。**不需要手动刷机、不需要命令行。**

**已验证**：2026-11-13 在真实 Zero 2 上自动刷入 `1.08.1`（翻页器映射）成功，
updateLog 显示 `update successful`，固件头版本 108，设备重启回普通模式 `2DC8:9018`；
R+Start 键盘模式实测 **12/12 键输出正确**（PageUp/PageDown/Home/End/Esc/Enter/Space/Tab/Backspace/Delete/Left/Right）。

## 运行

- **首次使用先下载官方固件**（仓库不包含 8BitDo 固件二进制）：
  ```
  python firmware-patch/download_official_firmware.py
  ```
  生成 `firmware-patch/Zero2_V1.08.dat`（GUI 发现缺文件时也会自动下载）。
- **双击桌面快捷方式 `8BitDo Zero2 改键刷写`**（无黑框：快捷方式调用 `wscript 启动.vbs`，由 `pythonw` 启动界面）。
- 也可以双击本目录 `启动.vbs`（无窗口），或 `启动.bat`（内部同样转给 VBS，只在双击 bat 时闪一下）。
- 依赖：Windows 10/11 + Python 3.8+（需带 tkinter；官方安装包默认自带）。
- **在普通 Windows 会话里运行**（不要在 DSH 沙箱里跑刷写：沙箱会拦官方更新器写设置）。
- 第一次运行会生成 `config.json`（保存映射与下一次的 `1.08.N`）。

## 使用步骤

1. 手柄**普通模式**连接：按一下 START 开机 → 插 USB（不要按 L+R+START 手动进升级模式）。
   右上角状态显示「已连接（普通模式 2DC8:9018）」，否则点「刷新设备」。
2. **点手柄示意图上的某个键**（会亮蓝圈），在右侧「当前按键」里选它要输出的键
   （可直接输入键名，或 HID 码如 `0x4B`）。标签由引线指向按键、位置固定，不需要手动排版。
3. 改满意后，在「我的设定」里填个名称 → 点「保存设定」；以后从「载入」下拉框选中即恢复。
4. 点「刷写到手柄」，等日志出现成功提示（约 15 秒，期间别拔线）。
5. 拔线 → **R+Start** 开机（键盘模式）→ 在目标设备蓝牙里连接 `8BitDoZero 2 gamepad` → 测试按键。
6. 想换布局就改完再刷一次；标签会自动变成 `1.08.2`、`1.08.3`…

## 我的设定（保存 / 载入）

- 键位改好后，在「我的设定」里输入名称（如「翻页器」「课堂批注」），点 **保存设定**；
- 名字和 12 个键位会存进 `saved_profiles.json`；
- 以后在「载入」下拉框里选中该名称，会自动恢复这套键位（再点刷写即可）；
- 当前键位同时会写入 `config.json`，关掉重开也会恢复上次的状态。

## 版本规则（1.08.N）

- 固件基于**官方 1.08**（解密 → 改 12 字节键位表 → 重新加密）。
- 我们自己的标签是 `1.08.1`、`1.08.2`…（每次刷写成功后 N 自动 +1）。
- 固件头里的数字版本保持 `108`（官方 1.08 基线），对更新器报的列表版本是 `1.08 + N/1000`
  （1.081、1.082…）。官方更新器界面只显示两位小数，所以界面里会显示 `V1.08`，
  但内部比较是 1.081→1.082 递增，可连续刷；设备内版本也保持 1.08 基线。
- 想固定/重置编号：改 `config.json` 里的 `patch`（或删掉整个 config 重新开始）。

## 安全性设计（针对早期翻车做的加固）

- **不改系统代理/注册表**：只给官方更新器写一个临时的 `8BitDo Firmware Updater.exe.config`
  （defaultProxy 指向本地代理），用完还原。
- **刷前清下载缓存**：更新器会复用 `updateFile\zero2-custom.dat`（只要长度对得上就不重新下载，
  内容变了也不管）——每次刷写前自动删除，防止刷进旧固件。
- **校验下载与版本**：要求代理真的收到 `/firmwareFile/upload/...` 下载请求；
  刷完解析 updateLog 里的 `Version:` 与固件头比对，不一致会告警。
- **失败不杀进程**：超时/失败时保留更新器窗口，方便查看错误；成功才自动关闭。
- 刷坏/卡在升级模式的恢复：**直接打开官方更新器，用官方固件刷回 1.08**（已实测可行，不用拆机）。

## 命令行（可选/自动化）

```powershell
python zero2_kb_gui.py --build --preset "翻页器" --patch 1    # 只生成 1.08.1 的 .dat
python zero2_kb_gui.py --flash --preset "翻页器" --patch 1    # 生成并刷写
python zero2_kb_gui.py --selftest                             # 自检
```

## 文件

| 文件 | 说明 |
|---|---|
| `zero2_kb_gui.py` | GUI + CLI 入口 |
| `fwlib.py` | 固件生成（解密官方 v1.08 → 改 12 字节表 → 重加密） |
| `flasher.py` | 本地代理 + app.config 代理 + 更新器窗口自动化 + 结果/版本校验 |
| `hidmap.py` | HID 键码表、12 键顺序（命令行 --preset 仍可用内置预设） |
| `controller_small.png` | 界面用手柄底图（官方 8BitDo 产品渲染图裁剪/缩放，仅展示用；标签在图片外，用细引线指向按键） |
| `controller_base.png` | 底图原尺寸版本（660×330，重新生成小图用） |
| `config.json` | 运行后生成：保存当前映射与下一次的 `1.08.N` |
| `saved_profiles.json` | 「我的设定」：命名保存的键位方案 |
| `启动.vbs` | 无黑框启动器（wscript → pythonw），桌面快捷方式指向它 |
| `启动.bat` | 兼容入口（转给 启动.vbs） |
| `_gui_shot.png` | 界面截图 |
